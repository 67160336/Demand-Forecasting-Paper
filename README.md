# PulpFlow — ระบบพยากรณ์ยอดสั่งซื้อกระดาษล่วงหน้า

Frontend สำหรับอุตสาหกรรมเยื่อและกระดาษ ใช้ทำนายยอดสั่งซื้อกระดาษล่วงหน้าและวางแผนวัตถุดิบ

## หน้าจอ
- **หน้าแรก** — นำเข้าข้อมูล CSV หรือใช้ข้อมูลตัวอย่าง
- **พยากรณ์ยอดขาย** — กราฟแนวโน้ม + พยากรณ์ตามเกรดกระดาษ
- **วางแผนวัตถุดิบ** — คำนวณเยื่อ/สารเคมี/น้ำที่ต้องใช้ และส่งออก CSV

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิดที่ http://localhost:5173

## Build สำหรับ deploy

```bash
npm run build
```

ไฟล์ที่ build แล้วจะอยู่ในโฟลเดอร์ `dist/`
